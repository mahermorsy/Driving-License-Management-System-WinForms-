# Driving License Management System

Windows Forms desktop application for driving license management using C#, ADO.NET, SQL Server, and 3-Tier Architecture principles.

---

## Features

- Driver management
- License issuance and renewal
- User authentication and permissions
- Local database integration using SQL Server
- Layered architecture (Presentation, Business, Data Access)

---

## Technologies Used

- C#
- Windows Forms
- ADO.NET
- SQL Server
- 3-Tier Architecture
